---
name: cost-reporting
description: How to report a number computed from structured storage (a spreadsheet/CSV table). Use when the answer is backed by a deterministic calculation over tabular cost data.
---
State the exact computed value explicitly (e.g. "$3,580"), never round it away
into a vague range. Say plainly that the number was computed directly from
the underlying table, not estimated or guessed — name the source file and the
column it came from. If the question also touched unstructured docs (guides,
pricing pages), keep that context, but the computed number is the answer's
anchor, not a footnote.
