# Plans and pricing

The price is made up of a base plan plus a separate GPU-inference plan.
Plans update quarterly; a change takes effect at the start of the next quarter.

## Base plans

- Starter — for individual projects: basic calculations and storage of up to 5 projects;
- Professional — team work, Git and BIM editor integrations;
- Enterprise — SSO, priority support, configurable limits.

## GPU inference

Heavy neural-network calculations (layouts, design option generation, material
classification) run on GPU nodes and are billed separately by the number of
nodes used.

In Q2 the GPU-inference volume grew and added 43% to total infrastructure
costs: additional inference workers were deployed. Billing is per actual
usage, so load growth is reflected directly in the invoice.

## What is included

- project and version storage;
- access to the material catalog;
- estimate and plan calculations;
- API and web console.
